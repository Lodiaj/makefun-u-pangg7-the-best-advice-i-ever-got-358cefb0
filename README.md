One sentence of the best advice I ever received, written by a small program.
`main.ts` writes a single sentence to `/output/entry.txt`.

The advice:

> When I was seventeen and wanted a loan for a car I could not afford, my father said never borrow money to look rich, because the people you are trying to impress will be gone long before the debt is.

## Run

```sh
node main.ts
```

It writes the advice to `/output/entry.txt` (1–200 characters, a single sentence, one line).
